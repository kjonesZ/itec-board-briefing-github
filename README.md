# ITEC Board Briefing

Board briefing for Sinclair College’s Integrated Technology Education Center. It includes the Building 8 floor plans, the Instructional Server Center, the APT manufacturing example, and the Working and Teaching SNOCs.

Open `index.html` in a browser with the accompanying files and `assets` folder. The single-file `ITEC Board Briefing.html` includes the site and its assets for offline use. Use **Print brief** for the one-page handout.
